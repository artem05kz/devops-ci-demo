# devops-ci-demo

Учебный проект к практической работе № 4 «Практики DevOps в современных методологиях
разработки» по дисциплине «Методологии разработки программного обеспечения».

Репозиторий содержит простое веб-приложение и описание конвейера непрерывной
интеграции и доставки в виде файла `Jenkinsfile`.

## Состав репозитория

```
devops-ci-demo/
├── Jenkinsfile                 описание конвейера CI/CD
├── VERSION                     версия приложения
├── .gitattributes              принудительные LF в скриптах
├── src/
│   ├── index.template.html     шаблон страницы с метками подстановки
│   ├── styles.css              стили
│   └── app.js                  клиентский сценарий
└── scripts/
    ├── build.sh                сборка дистрибутива
    ├── test.sh                 проверки дистрибутива, отчёт JUnit XML
    ├── analyze.sh              статический анализ исходного кода
    └── deploy.sh               развёртывание в окружение
```

## Этапы конвейера

| Этап | Что выполняется |
| --- | --- |
| Подготовка | Очистка рабочей области, вывод сведений о сборке |
| Сборка | `build.sh` — подстановка версии и номера сборки в шаблон |
| Тестирование | `test.sh` — 9 проверок дистрибутива, отчёт в JUnit XML |
| Статический анализ | `analyze.sh` — поиск TODO/FIXME, секретов, проверка обязательных файлов |
| Упаковка | Архив `tar.gz`, публикация артефактов сборки |
| Развёртывание | `deploy.sh` — развёртывание и проверка доступности |

## Запуск вручную

```sh
chmod +x scripts/*.sh
./scripts/build.sh
./scripts/test.sh
./scripts/analyze.sh
./scripts/deploy.sh staging
```

## Параметры конвейера

- `DEPLOY_ENV` — окружение развёртывания: `staging` или `production`.
- `RUN_TESTS` — выполнять ли этап тестирования.
